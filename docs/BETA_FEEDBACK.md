# Student beta feedback

Student Beta v0.1 is not yet open for general use. When the release gates pass, feedback can be submitted through the PyLake GitHub repository's Issues page, if issues are enabled.

Please include:

- The application version or commit you tested.
- The route and steps that led to the problem.
- Expected and observed behavior.
- Sanitized error text and relevant request IDs.
- Browser, operating system, and whether Docker or local services were used.

Do not include uploaded data, SQL containing private values, passwords, cookies, access tokens, database URLs, or storage credentials. Remove workspace and user identifiers from screenshots and logs where practical. GitHub issues are public unless repository settings state otherwise; do not submit private security reports there.

No response-time commitment or support channel has been established for the beta.
